🚀 About This Project

This project is a full-stack URL Shortener application designed to convert long and complex URLs into short, easy-to-share links. It demonstrates real-world backend development, authentication systems, and frontend integration.

📌 What is a URL Shortener?

A URL shortener is a tool that takes a long web address and transforms it into a short, compact link. When users click the shortened link, they are automatically redirected to the original URL.

Example:

Original → https://www.example.com/products/item/very-long-url

Short → https://your-domain.com/redirect/abc123

⚙️ How It Works

  • User enters a long URL in the input field
  • Backend generates a unique short ID using hashing
  • Original URL and short ID are stored
  • Short link is returned to the user
  • When visited, the system redirects to the original URL

🧠 Core Concepts Used

🔹 Hashing (MD5)

The application uses hashing to generate a fixed-length unique ID from a URL. This ensures fast processing and avoids duplicate entries.

🔹 REST APIs

The backend exposes API endpoints such as /shorten, /login, and /register to handle communication between frontend and backend.

🔹 JWT Authentication

Secure user authentication is implemented using JSON Web Tokens. Users must log in to generate short URLs.

🔹 Password Security (Bcrypt)

Passwords are hashed before storage using bcrypt to ensure security and prevent data leaks.

🔹 HTTP Redirection

The backend uses HTTP redirect responses to send users to the original URL when they access a shortened link.

🔹 In-Memory Storage

Currently, data is stored using Go maps. This can be replaced with databases like MongoDB or MySQL for scalability.
